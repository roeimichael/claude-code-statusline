# Issue tracker: GitHub

Issues and specs live in `roeimichael/claude-code-statusline`. Use `gh` with `--repo roeimichael/claude-code-statusline` explicitly when working from a fork.

- Read: `gh issue view NUMBER --repo roeimichael/claude-code-statusline --comments`.
- List: `gh issue list --repo roeimichael/claude-code-statusline`.
- Publish: `gh issue create --repo roeimichael/claude-code-statusline --title TITLE --body-file PATH`.
- Update comments and labels through `gh issue comment` and `gh issue edit`.

PRs as a triage surface: no. Review a PR when the user directly requests it.
